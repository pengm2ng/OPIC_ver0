# Context Speak Premium

총 카드: 1,175개

## 포함 기능
- 한국어 문맥 → 영어 표현 말하기
- 카테고리/전체/검색/즐겨찾기/미학습
- 맞음·틀림 및 누적 정답률
- 오답노트, 오답에서 개별 삭제
- 삭제해도 '자주 틀린 순' 기록 유지
- 간격 반복(SRS) 복습 일정
- 오늘의 학습 10~50문제 설정
- 영어 정답 음성 재생
- 브라우저 기본 음성 인식(지원 기기)
- 오픽 질문 모의시험
- 90초 타이머 및 음성 녹음·재생
- 카테고리별 통계, 연속 학습일
- 다크모드
- JSON 백업/복원
- 오프라인 PWA
- 로그인, 서버, 유료 API 없음
