# OPIc Context Vocab — iPhone PWA

## 포함 기능
- 문맥형 카드 120개
- 한국어 특정 표현 빨간 강조
- 탭하면 정답·전체 영어 문장·용법 표시
- 맞음/틀림 기록
- 오답노트 및 오답 재시험
- 카테고리, 전체 목록, 검색, 즐겨찾기
- 학습 통계
- 데이터 백업·복원
- 다크 모드
- 홈 화면 설치 및 오프라인 실행

## 배포
1. 압축을 풉니다.
2. Netlify Drop에 `opic-context-vocab-pwa` 폴더 전체를 올립니다.
3. 생성된 https 주소를 아이폰 Safari에서 엽니다.
4. Safari 공유 메뉴 → 홈 화면에 추가를 선택합니다.

중요: `index.html`이 폴더 최상단에 있어야 합니다.

## 데이터 확장
`data.js`의 배열에 같은 구조의 카드를 추가하면 됩니다.
학습 기록은 서버가 아니라 아이폰 브라우저 내부(localStorage)에 저장됩니다.
사이트 데이터를 삭제하거나 다른 기기로 옮기기 전에는 설정 → 데이터 백업을 사용하세요.
